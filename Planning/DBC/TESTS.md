# Tests

Tests are mapped to [CONCEPTS](CONCEPTS.md), [CODE](CODE.md), [DEFINITIONS](DEFINITIONS.md)
and [BENCHMARKS](BENCHMARKS.md). Verification and validation cases of the physics are in
BENCHMARKS; this file lists the automated tests.

| Test | Checks | Concepts |
| --- | --- | --- |
| `tools/toolchain/tests/test_check_toolchain.py` | Version parsing, manifest comparison and rendering of the toolchain check; GoogleTest and Eigen read through pkg-config; an unknown package fails as unrecognised version output with its install hint | `ToolchainPin` |
| `tests/unit/common/invariant_test.cpp` | A violated invariant check aborts with expression, message, file, the exact line and the function on stderr; the condition is evaluated once; the message is not evaluated when the condition holds. Runs in every preset, release included | `RuntimeChecks` |
| `tests/unit/common/floating_point_test.cpp` | An invalid operation, a division by zero and an overflow each stop the program with SIGFPE in the debug and sanitizer presets, also when the binary runs without the presets' sanitizer options, and yield NaN, +∞ and +∞ in release; underflow and inexact results never trap | `RuntimeChecks`, `BuildPresets` |
| `tests/unit/common/diagnostic_test.cpp` | A diagnostic reads `file: location: entry: message`, the entry part left out when empty | `LibraryReader` |
| `tests/unit/io/nodal_library_test.cpp` | A valid library built in C++ (`tests/unit/io/library_fixture.cpp`; variable-length, NUL- and space-padded fixed-length strings) is read field by field; all four axes, of lengths 2, 3, 4 and 1, in vocabulary order with the last axis fastest; a set without axes as one state; several sets in name order; unknown members ignored; optional quantities absent. Rejected, each problem at its dataset or attribute with its message and every problem reported together: a missing file, a file that is not HDF5, format version (the sets then left unchecked), group counts other than 2 and 8, each missing root attribute, a group boundary that is NaN, ±Inf, 0 or negative, root attributes of the wrong type or shape, no group of sets or no set, each missing required quantity, a quantity that is not a group, a missing or non-float64 `value` or `std_dev`, missing or wrong units (both moderator axes included), a wrong shape, an unknown axis, an axis that is not a 1-D float64 dataset, `axes` not a group, non-ascending, repeated, non-finite and out-of-bound axis points, missing, non-string, 2-D, empty, empty-named or repeated names, missing, non-uint8 (uint16 included) or wrong-shaped flags, flags other than 0 and 1, a dataset HDF5 cannot read (the read goes on), entry rules alongside structural problems and alongside flags other than 0 and 1. Every component of every quantity (both energy groups, all eight delayed groups, all twelve face-group factors) broken by its sign rule, NaN or ±Inf in the value or by a negative, NaN or ±Inf standard deviation, with two boron points and with a one-point boron axis: rejected while marked valid, naming composition, branch state, component and the broken rule as the contract writes them; read once marked invalid, the entry then counted and named by the check of used compositions. Quantity names, units, components and rules match the contract table; zero decay constant allowed exactly where the same group's β = 0, in each delayed group; delayed fractions summing to 1 or more rejected, near the largest double without overflow; at most 20 diagnostics per dataset, then the number not listed, also for the check of used compositions; only the compositions in use are checked; an entry outside the set aborts | `LibraryReader` |
| `tests/end_to_end/present_library_test.cpp` | The present library, written by the library writer, is read: one set `beavrs_full_core` of 7650 compositions named by rod state and mesh position, fuel temperature, moderator density and boron axes (36 branch states); entries breaking a rule per quantity match TM §19.3 (D 46 and 79, Σa 41 and 77), with effective Σ12 222, 1/v 41 and 77 and every other quantity 0; the 227 invalid entries each break a rule and lie in the 32 corner columns of a plane; every other composition (3281 per rod state) is usable | `LibraryReader`, `LibraryContract`, `FullCoreReference` |
| `external/BEAVRS_minimal/test_library_writer.py` | On synthetic runs: ±1.8 × 10³⁰⁸ restored to ±∞; effective down-scatter and its propagated standard deviation by hand, NaN where the fast flux is 0; delayed fractions bit-identical with the loop that wrote the old library, their standard deviation against finite differences; κΣf in joules; every entry rule (zero, NaN, ±∞, negative; a delayed-fraction sum of 1; a zero decay constant with a positive fraction); validity flags from values and standard deviations, only the broken entries marked; branch state from materials (fuel temperature, boron, water density), a water density not in g/cc rejected; rod state from the run directory; composition names; run directories selected by name; a missing run, a repeated branch state and two moderator temperatures at one density rejected; a written library read back with its run index; the reproduction check passing and failing on a one-bit change | `FullCoreReference`, `LibraryContract` |
| `tools/ci/tests/test_license_headers.py` | Header accepted after an optional shebang with either comment prefix; missing, short, wrong-prefix, wrong-copyright, wrong-license and out-of-range-year (before 2026 or after this year) headers reported; file selection keeps our code files and skips `external/`, JSON, data and the concept-map checker; a run that finds no code file of ours fails | `LocalCi` |
| `tools/ci/tests/test_local_ci.py` | Steps cheapest first with clang-tidy last; each preset step configures, builds and tests its own preset; each other step runs exactly its command; an `--only` run that leaves a step out prints `SKIP` for it and never claims a full pass, one naming every step is a full run; `--list`; a failing or missing command fails its step without a crash; the run stops at the first failure and prints its tail; clang-format and clang-tidy fail on an empty selection, clang-tidy also when the compile database lacks an engine source, and on any finding | `LocalCi` |
